# 1.21.1 音乐包学习样本（含音频）

这里提供三个从 1.21.1 实例整理的完整音乐包，供查看 `pack.json`、音频键和 Ogg 文件的组织方式。它们分别是 `官方默认包`、`6e2304d0`（悠闲版本）、`dd1a42e5`（经典包／双语音）。各目录可复制到客户端 `config/crafty_cards/soundpacks/` 试用；模组 jar 本身不含音频。
