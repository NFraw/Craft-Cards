## 一句话简介

在 Minecraft 世界里与两位朋友玩斗地主：放下牌桌、叫地主、选牌出牌，再由服务器结算胜负。

## 简短描述

Crafty Cards 在 Minecraft 中提供三人联机斗地主：HUD 展示自己的手牌与倒计时，牌局发生在世界中的牌桌旁。支持主动观战、按桌设置的可选物品筹码，以及客户端音乐包。

## 完整描述

合成并放下一张斗地主牌桌，三名玩家右键入局后自动发牌。玩家依次叫分，使用滚轮移动手牌焦点、左键选牌、右键牌桌出牌或过牌。服务端负责发牌、牌型校验、回合、胜负和筹码结算；客户端按权限接收牌局状态，不会默认拿到其他玩家的手牌。

牌局没有全屏游戏界面：你能继续看见桌子与周围世界，自己的牌与倒计时显示在 HUD 中，其他参与者的牌显示在他们身前。局外玩家可以主动开启观战；是否允许看牌面由服务器决定。

每张桌子可由房主设置筹码类型、底注和入局门槛，也可关闭筹码进行纯娱乐局。模组 jar 不包含音频；希望听到语音、音效和背景音乐时，在各客户端安装并选用单独的音乐包。

**安装范围：**Minecraft Java 版 1.21–1.21.11；NeoForge、Fabric、Forge 分别使用各自安装包。Forge 1.21.2 无目标包。需要 Java 21；Fabric 安装还需要与 Minecraft 版本匹配的 Fabric API。客户端与服务器应使用相同 Minecraft 版本、相同加载器及对应模组包。

**当前版本的边界：**仅支持三名真实玩家联机，没有 AI 或单人入口；尚未验证跨加载器混服。自动对局通过不等于每个分辨率下的 HUD 画面与音乐实际听感都已人工确认，请参阅随版本提供的验收记录。
