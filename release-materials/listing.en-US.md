# English listing copy

**Title:** Crafty Cards  
**First-release subtitle:** Dou Dizhu  
**Mod ID:** `crafty_cards`  
**Author:** JokerNan

## One-line summary

Play three-player Dou Dizhu in your Minecraft world: place a table, bid for landlord, play cards, and settle the round on the server.

## Short description

Crafty Cards brings three-player Dou Dizhu into Minecraft. Your hand and turn timer appear in the HUD while the match remains in the world. Optional item stakes, opt-in spectating, and client-side sound packs are supported.

## Full description

Craft and place a Dou Dizhu table. Three players join by interacting with it, then the table deals 17 cards to each player and three bottom cards. Players bid for landlord, use the mouse wheel to focus a card, left-click to select cards, and interact with the table to play or pass. The server controls the deck, validates turns and card combinations, and settles the result and any item stakes. Each client receives only the card information it is allowed to see.

The match takes place in the Minecraft world instead of a full-screen game screen. Your cards and countdown appear in the HUD, and cards held by other players appear in front of them. Spectators must opt in, and the server controls whether they can see card faces.

The table host can configure the chip item, stake, and entry requirement for that table, or disable chips for a casual game. The mod jar contains no audio files. To hear voice lines, sound effects, and background music, install and select a separate sound pack on each client.

**Compatibility:** Minecraft Java Edition 1.21–1.21.11, with separate builds for NeoForge, Fabric, and Forge. There is no Forge target for Minecraft 1.21.2. Java 21 is required; Fabric users also need a matching Fabric API. Client and server must use the same Minecraft version, loader, and matching Crafty Cards build.

**Current limits:** Three real players are required; there is no solo or AI mode. Mixed-loader servers have not been verified. Passing automated matches does not establish that every display resolution or audio device has been manually checked; consult the version's acceptance evidence.
