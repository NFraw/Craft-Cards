# 1.21.1 三个音乐包：来源与再分发风险

本地 1.21.1 NeoForge 实例中有三份带有效 `pack.json` 的音乐包：`官方默认包`、`6e2304d0`（悠闲版本）和 `dd1a42e5`（经典包／双语音）。另外三个目录没有 `pack.json`，不构成可安装音乐包，未纳入。三包作为带音频的结构学习样本收入仓库 `learning-soundpacks/`，另备独立 zip 与三包合集供下载。

| 包 | 音频键 | 打包音频文件 | 已确认的来源风险 |
| --- | ---: | ---: | --- |
| 官方默认包 | 54 | 54 | 本地旧导入记录表明，50 条语音取自另一项目，4 段 BGM 由该项目 MP3 转码而来；其中 50 条语音与该项目的音频逐字节相同。原 `pack.json` 声称“作者自有素材，可自行再分发”，与溯源记录冲突；打包副本已移除这句不实许可声明，未改音频。 |
| 悠闲版本 | 54 | 104 | 与上述另一项目至少有 52 个音频文件逐字节相同；原目录另有 2 个未被 `pack.json` 引用的 Ogg，打包时已剔除。 |
| 经典包（双语音） | 61 | 110 | 与官方默认包 54 个音频逐字节相同，与另一项目至少有 53 个音频逐字节相同；新增素材的每项来源与授权仍需核对。 |

另一项目的公开 README 明确说：其斗地主语音和背景音乐来自他人作品，已从公开仓库移除；其软件的 MIT 许可针对代码，**不能据此推定音频也获得 MIT 授权**。此外，三个包互相复用大量相同录音，不能因为显示作者是 `JokerNan` 或 `Crafty Cards`、文件在本机、曾经能够在 1.21.1 播放，便认为项目拥有录音、配音、词曲和传播权。转成 Ogg、剪辑、重命名、注明来源、免费发布或写“可能侵权”的免责声明，也不会自动取得再分发许可。官方默认包原先的“作者自有素材，可自行再分发”表述应视为**已撤回，不能引用**。

把这些 zip 上传到公开 GitHub Release，属于向公众提供音频副本。应先逐项取得能覆盖**复制、公开分发、网络传播及必要改编/转码**的许可，或用权利清楚的原创/授权音频替换；必要时同时核对词曲作者、表演者、录音制作者等权利。中国国家版权局公布的[《著作权法》第四十四条](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html)涉及录音制品的复制、发行和网络传播许可；[WIPO 的版权常见问题](https://www.wipo.int/en/web/copyright/faq-copyright)也说明使用受保护作品通常需要授权。此处是发布风险提示，不是对每段录音的最终权属或侵权结论。

**非盈利、在 GitHub 找到文件、注明来源，以及打算“收到通知再下架”，都不能保证有再分发权或把后果限制为一次警告。**[GitHub 的 DMCA 政策](https://docs.github.com/en/site-policy/content-removal-policies/dmca-takedown-policy)允许在某些情况下直接停用整个仓库或包，并规定反复侵权时可终止账号；[中国《著作权法》第五十二至五十四条](https://www.ncac.gov.cn/xxfb/flfg/flfg_532/202103/t20210309_50530.html)列有停止侵害、赔偿等责任，并非以是否盈利作为唯一条件。具体责任取决于事实、适用法律和权利人的主张，不能预设“最多下架”。

**当前处理：**项目作者要求将三包作为音乐包结构学习样本公开，并在仓库与 Release 中附上音频。本说明如实披露尚未逐项确认公开分发授权的风险；“学习用途”和删除期限均不构成授权。**如有侵权，请联系下架。**音乐包制作工具可帮助玩家制作自己的包，使用者应选择自己有权使用的素材。
