# 快速制作音乐包：给助手的提示词

把下面的提示词交给能访问 Crafty Cards 仓库和本机音频文件的助手。**推荐批量处理**：制作程序按文件名识别 61 个音频键，`--dry-run` 可先预览映射且不写盘；确认无误后再生成。图形界面适合只改少数条目，不必为了几十条语音逐行点击。

准备一份有使用权的音频目录；若音频来自已有音乐包，也可以给助手那个包的 `pack.json` 路径。目标实例不确定时，可先用仓库的 `run/config/crafty_cards/soundpacks` 开发目录。音频键含义见[音乐包格式](音乐包格式.md)。非 Ogg 源文件需要 PyAV（`pip install av`）转码。

```text
请帮我用 Crafty Cards 仓库里的 tools/soundpack_maker.py，快速制作可在游戏内选用的音乐包。

源音频目录或已有音乐包的 pack.json：【绝对路径】
显示名：【填写；留空时用源目录名】
作者：【填写；可留空】
简介：【填写；可留空】
目标 Minecraft 实例的 config/crafty_cards/soundpacks 目录：【绝对路径；不确定可用仓库 run/config/crafty_cards/soundpacks】
用途说明与偏好：【例如“每个非 BGM 键最多两条不同语音，权重相同”；可留空】

请按以下方式完成：
1. 检查音频文件、来源和已有 pack.json。若有 pack.json，优先按其中的键映射理解文件；不要仅凭 n1.ogg 等简写文件名猜用途。没有清单时按文件名、目录名和我的说明识别；实在无法确定的少数文件列出来问我。不要为了填满 61 个键而复制同一声音或编造内容。
2. 在临时整理目录中保留原文件，按音频键准备可批量识别的文件名：pass_1.ogg、pass_2.ogg → pass；dan1_1.ogg → 单张 A；bgm_playing.ogg → 对局 BGM。多条等权重时不写权重标记；需要特定权重时在文件名加 _wN（1–99）。同键候选先按文件内容去重，BGM 与一次性音效不要混用。
3. 运行 python tools/soundpack_maker.py --cli <整理目录> --name <显示名> --author <作者> --desc <简介> --out <输出根目录> --dry-run。核对识别出的键、每个源文件和权重，以及被忽略的文件。此步不得创建音乐包；需要修正时调整临时目录，再预览一次。只有影响映射、版权或目标实例的歧义才问我。
4. 映射明确后，用同一命令去掉 --dry-run 生成。制作程序会分配空闲包 id，把音频复制或转码到新包目录并写 pack.json。不要覆写别人的现有包；不要发布、上传或分享文件。
5. 验证 pack.json 的键、每键候选数量和权重；检查每个被引用的文件都存在且可解码为 Ogg Vorbis。列出尚未覆盖或需要我试听核对的键，并告诉我在游戏内「配置 → 音乐包 → 扫描 → 选用 → 保存并应用」的位置。

不要把本地音频、路径或个人信息发到外部服务。对来源或再分发权不明确的素材，只做本地个人包并注明待核对。
```

## 命名速查

| 例子 | 识别结果 |
|---|---|
| `pass_1.ogg`、`pass_2.ogg` | 过牌两条，默认权重各 1 |
| `pass_2_w3.mp3` | 过牌候选，权重 3；生成时转成 Ogg |
| `dan1_1.wav` | 单张 A；生成时转成 Ogg |
| `bgm_win.ogg` | 结算胜利 BGM；`win.ogg` 才是一次性结算音效 |

制作程序无法识别的名字会在预览中列出，不会静默塞进某个键。缺少素材的键可以留空：牌型语音退回通用出牌音效，音效退回原版；残局和王炸 BGM 有回退链，其余未配置的 BGM 不播放。
