# 安装与游玩 · neoforge / Minecraft 1.21.2

本分支对应 Crafty Cards 1.0.0 的 **neoforge / Minecraft 1.21.2** 安装包：`build/mc-1.21.2/libs/crafty_cards-neoforge-mc1.21.2-1.0.0.jar`。客户端与服务器都必须使用 Minecraft 1.21.2 和 neoforge，将该 JAR 放入各自的 `mods` 目录。Fabric 还需要 Fabric API 0.106.1+1.21.2。`-sources.jar` 仅供阅读源码，不能安装。其他加载器和 MC 版本须下载对应分支。

需要音乐时，另将音乐包复制到每位客户端的 `config/crafty_cards/soundpacks/`；模组 JAR 本身不含 `.ogg`。

## 一局怎样开始

1. 合成并放置斗地主牌桌：第一排中间一块绿地毯，第二排三块木板，第三排两侧各一根木棍。
2. 局外第一位玩家在牌桌旁 **Shift + 右键**成为房主，设置这张桌子的筹码类型、底注、入局门槛，也可关闭这桌的筹码。全服总开关 `chipsRequired=false` 也可让所有桌子变成娱乐局。
3. 三名玩家依次右键牌桌入局。启用筹码时，必须备足本桌入局门槛；每人入局会实收本桌底注。坐满自动发牌，每人 17 张，底牌 3 张。
4. 叫分阶段滚轮选“不叫/1/2/3”，轮到自己时右键桌面确认。出牌阶段滚轮移焦点，左键选牌，右键桌面出牌或过牌；右键空气清除选择。HUD 显示自己的手牌、当前回合和倒计时。
5. 结算后点击关闭结果。局中 Shift + 右键离桌、掉线或超时会按判负规则处理，切勿将离桌当成无损退出。

非参局者靠近桌子 Shift + 右键可主动切换观战；是否看见牌面由服务端配置决定。牌局需要三名真实玩家，没有 AI 或单人入口。

## 配置归属

| 路径 | 运行端 | 何时生效 | 说明 |
| --- | --- | --- | --- |
| `config/crafty_cards/server.json` | 服务端 | 重启服务端 | 全局玩法、筹码白名单、入局距离、限时与可见性；已有桌子的筹码设置保存在方块实体里 |
| `config/crafty_cards/visual.json` | 客户端 | `/craftycards reload` 或重启 | HUD、世界手牌、桌面出牌、筹码的渲染参数 |
| `config/crafty_cards/sounds.json` | 客户端 | 游戏内保存并应用或重启 | 音频开关、音量、当前音乐包 |
| `config/crafty_cards/soundpacks/<包id>/` | 客户端 | 扫描、选用并保存应用 | `pack.json` 与 Ogg 音频 |

连专用服务器时，玩家本机的 `server.json` 不控制服务器。游戏内房主设置的是**每张桌子**的筹码参数；全局配置要在服务器上改。详细键表见 [项目首页](../../README.md) 和 [音乐包格式](../音乐包格式.md)。

## 排查

- **无法入局**：检查是否凑齐三人、距离是否在 `joinRadius` 内、是否配置本桌筹码与备足门槛；娱乐局不要求筹码。
- **牌面不清晰或位置异常**：确认包与 Minecraft 版本匹配，先用默认 `visual.json`，记录加载器、GUI 缩放、窗口/全屏分辨率，并与 [自动化验收总览](../evidence/multi-version-2026-09-27/README.md) 的 NeoForge 1.21.1 基准截图比较。
- **音乐包没有声音**：确认每台客户端各自安装并选用包，保存后触发资源重载；检查 `latest.log` 中 `Missing sound for event:`。自动化只能证明事件资源存在，实际播放还要听音。
- **服务器拒绝连接**：先核对三个版本信息和 Fabric API；提交问题时附双方 `latest.log` 的相关片段，删除私人路径与账号信息。
