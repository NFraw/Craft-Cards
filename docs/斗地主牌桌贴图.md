# 斗地主牌桌素材与视觉辨识

## 文件与布局

贴图：`common/src/main/resources/assets/crafty_cards/textures/block/ddz_table_atlas.png`，32 × 32。
这张图提供可复用材质，桌布不再与木框画在同一个区域。每 1 UV 单位对应 2 像素。

| 区域 | UV | 内容 |
| --- | --- | --- |
| 左上 16×16 | 0,0 → 8,8 | 木质桌身，中央有三张牌的浅色标识 |
| 右上 16×16 | 8,0 → 16,8 | 可重复铺设的纯绿色桌布 |
| 左下 16×16 | 0,8 → 8,16 | 无标识木纹，用于直边与底面 |
| 右下 16×16 | 8,8 → 16,16 | 无标识木纹，用于转角 |

`models/block/ddz_table_base.json` 提供桌身四周、底面和中央桌布。
`models/block/ddz_table_rim.json` 提供四条直边和四个转角。
`blockstates/ddz_table.json` 使用四向连接状态和 multipart 组合桌身、木质或桌布直边、木质或桌布转角。
`models/block/ddz_table.json` 是相同部件的组合版，供物品模型引用。

整体外表仍是六面封闭的完整一格；桌布、边框顶面均位于 y=16。中央桌布覆盖 x/z=2..14，边框宽 2 个模型单位。各顶面区域互不重叠，不使用叠加在同一平面上的贴片。桌身、桌布、边框的纹理密度均为每个模型单位 1 像素。

破坏粒子 `ddz_table_particle.png` 从展开图左下角裁出（x=0..15，y=16..31），为 16×16 的无标识木纹；改木纹时应同步更新。

物品模型的第一人称左右手缩放保持 0.35，第三人称保持 0.25。物品栏保持旋转 [30,225,0]、缩放 0.625 和侧向光照，呈现三面立体图标。

## 多种游戏的视觉约定

当前斗地主使用绿色桌布与侧面“三张牌”图案。后续桌型建议使用两个独立信号：
- 桌布主色：远处快速区分游戏区域。
- 外边缘的专属图案：近处确认游戏类型，不能只靠颜色区别。

同一种游戏保持统一木质结构，颜色与标识由桌型确定。大桌中间保持干净，不在每个桌面单元重复印图案；只在外围的适量位置设置标识。不同游戏区域相邻时保留分界木框，连接判断应包括游戏类型，避免视觉上连成一桌但实际是不同玩法。

未来需要清楚显示完整名称时，可以增加准星指向后的名称提示；该提示尚未实现。其他游戏的颜色与图案等实际玩法确定后再分配，不预先占用颜色。

四向连接状态已实现：有相邻同类型方块的边缘改用桌布区域，没有相邻方块的边缘保留木框；转角两侧均连接时改用桌布，否则保留木质转角。16 种连接状态均覆盖完整顶面，不会因隐藏木框而产生空洞。`ddz_table_rim.json` 保留完整木框部件；物品模型使用组合版 `ddz_table.json`，继续显示单格桌的完整外框。

矩形桌的内部侧面由相邻实心方块剔除，三张牌标识只会显示在露出的桌身侧面。当前每个露出的侧面均有一个标识，尚未实现“大桌每边只挑一个位置放标识”的额外筛选。结构识别与统一会话见 [多方块牌桌](多方块牌桌.md)。

## 生成方式与提示词

使用内置 image_gen 编辑原简洁贴图，然后以最近邻缩放至 32×32。提示词如下：

```text
Use case: precise-object-edit. Edit the supplied simplified Minecraft Dou Dizhu table texture into a reusable MATERIAL ATLAS, rather than a complete tabletop image. Keep extremely simple vanilla Minecraft chunky low-resolution pixel art, muted medium brown wood and green cloth, no ornate trim, no gold, no gradients, no realistic grain.
One square opaque image with EXACT four equal quadrants, boundaries exactly at 50% width and height. Treat each quadrant as 16x16 logical pixels, entire sheet is a 32x32 pixel artwork enlarged with nearest-neighbor.
TOP LEFT: medium brown wood panel used on all four vertical table sides. Plain wood with very few low-contrast short pixel grain marks. At exact center include a SMALL clear cream icon of THREE overlapping playing cards, built of three simple cream rectangles with dark brown pixel outlines, total icon width about 8 logical pixels and height about 6. NO letters, NO numbers. This is the game identification marker for Dou Dizhu.
TOP RIGHT: pure muted green cloth tile from edge to edge, sparse barely-visible green pixel variation. Absolutely NO wood rim and NO symbols in this quadrant; it must repeat across large connected tables.
BOTTOM LEFT: plain medium brown wood material, matching top left wood, no icon, sparse subtle short horizontal marks. This will be sampled for separate rim strips and bottom face.
BOTTOM RIGHT: same plain medium brown wood material for reusable corner pieces, no icon, no frame, uniform low-contrast material.
No dividing lines, no margins, no labels, no perspective, no full furniture drawing. Preserve crisp flat pixels and exact quadrant alignment.
```
