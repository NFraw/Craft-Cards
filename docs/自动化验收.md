# 多版本自动化验收

在 Windows PowerShell、Java 21 和可显示 Minecraft 客户端的桌面会话中，从仓库根目录运行：

```powershell
.\tools\run-acceptance-matrix.ps1 -Versions 1.21.11 -Loaders neoforge,fabric,forge -StopOnFailure
```

已上机实测的 NeoForge 1.21.1 是人工对照基准。变更公共 HUD、资源或配置界面后先跑
`.\tools\run-acceptance-matrix.ps1 -Versions 1.21.1 -Loaders neoforge`，再看新版截图。
完整回归另跑 `.\gradlew.bat test runGameTestServer`；此前本地重跑得到 122 项单测和
35 项 GameTest 全过。

不指定版本和加载器时，脚本按版本顺序串行检查 Minecraft 1.21.1—1.21.11 的所有可用组合。Forge 1.21.2 标为 `UNSUPPORTED`；不会启动它。每个运行组合使用一个专用服务器和三个真实客户端；四个进程都在独立目录运行，并使用本批次的唯一 ID。测试客户端负责放桌、配置、加入、叫分、选牌、出牌、结算，并保存叫分、出牌、选中和结算截图。服务端检查牌桌与方块实体、正常结算和筹码总量。客户端还检查快照隐私、倒计时推进、世界渲染回调、资源模型以及音频资源包的加载与重载。

常用选择：

```powershell
# 先检查四个启动配置与测试代码，不启动游戏
.\tools\run-acceptance-matrix.ps1 -Versions 1.21.11 -Loaders neoforge,fabric,forge -CompileOnly

# 逐个测试指定版本，失败后继续收集其他组合
.\tools\run-acceptance-matrix.ps1 -Versions 1.21.6,1.21.9,1.21.11

# 提高单组合外部时限
.\tools\run-acceptance-matrix.ps1 -Versions 1.21.11 -TimeoutMinutes 35

# 同一局分别截图窗口 HUD 和全屏（GUI 自动缩放）HUD，再完成对局
.\tools\run-acceptance-matrix.ps1 -Versions 1.21.11 -Loaders neoforge,fabric,forge -Fullscreen

# 已缓存对应构建依赖时，Forge 可离线运行，避免仓库连接超时导致编译类路径不全
.\tools\run-acceptance-matrix.ps1 -Versions 1.21.5,1.21.6 -Fullscreen -ForgeOffline
```

脚本把每次批次的 `results.json`、`README.md`、逐组合构建日志放到 `build/acceptance-matrix/<批次ID>/`，把四份游戏日志、角色结果、结构化 `result.json`、截图放到各项目的 `build/poc/<运行ID>/`（现代版本位于 `build/mc-<版本>/poc/<运行ID>/`）。每批结束会更新单页总览 `build/acceptance-overview.html`，包含版本×加载器矩阵、选中组合的截图分类、进程状态、运行历史、单测记录和原始日志入口；也可以单独运行 `tools/generate-acceptance-dashboard.ps1` 刷新页面。先看矩阵中的异常，再选择组合逐图核对窗口与全屏、HUD、配置及结算。请保持总览与 `build` 目录的相对位置，以便浏览器打开截图和完整日志。旧结果不会当成本次通过证据。`PASS` 只表示这条自动化流程全部断言通过；`FAIL` 和 `TIMEOUT` 需查看相应日志；`NOT_RUN` 表示仅编译；`UNSUPPORTED` 表示没有该加载器版本。最终退出码为非零表示至少一个必测组合失败。

每次只运行一组四进程，避免边玩边重编译同一组运行类。运行前 25576 端口必须空闲；测试服务器只绑定本机地址。Forge 1.21.11 的测试启动器需要 JDK 8 作为构建工具链，默认读取 `build/modern-port/temurin8-path.txt`，也可用 `-Jdk8Path` 指定。Minecraft 游戏本身继续使用 Java 21。

本自动流程检验诊断音乐包的事件资源**存在且重载后仍在**，无法靠文件和程序断言证明扬声器实际播放、语音内容正确或听感正常。它检查设置主页、音乐包、玩法、渲染和本桌筹码配置页的关键标签与当前控件文字，并保存每页截图；设置页标题和左侧标签还做了像素可见性检查，防止文字因透明色而整块消失。小窗口下的截断、重叠与文字观感仍需人工看图。HUD 截图会自动采集并验证 PNG 格式；1.21.5—1.21.11 还检查手牌与底牌区域有可见的亮色牌面，防止错误 UV 把牌面画成纯灰块。牌堆叠放、遮挡和视觉可读性仍须与 NeoForge 1.21.1 基准截图人工对照。该流程使用开发运行环境；发布 jar 放入干净客户端与服务器的安装验收是另一层检查。当前自动场景仅有 `normal`（地主胜利），无筹码、农民胜利、离局判负、掉线、超时与存档重启仍须扩展。
